# examples

每个目录对应正文一章，目录名带章号。

```
examples/ch10-first-tool/
├── README.md        # 这个例子演示什么、对应哪一章
├── package.json     # 依赖锁定精确版本
└── src/
```

**硬性验收标准**：`npm i && npm start` 在干净环境下成功。

这是本书与一份拆解报告的本质区别 —— 拆解引用代码是为了举证，书引用代码是为了给模板。

本目录下代码采用 [MIT](./LICENSE)（与正文的 CC BY-SA 4.0 不同，方便你直接抄进自己的项目）。

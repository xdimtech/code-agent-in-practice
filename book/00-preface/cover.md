# Code Agent 实战：基于 Pi 从零构建

> 一本讲怎么用 [pi](https://github.com/earendil-works/pi-mono) 做出**能交付**的 Code Agent 的书。
> 兼谈国内三家大模型厂商如何在同一个上游之上各自做产品，以及两个独立对照组的不同解法。

---

pi 的核心循环是 **794 行纯函数**。

围绕它的产品层是 **6 万行**。

这本书讲的就是这 6 万行里哪些你需要、哪些你要自己写、以及已经有三支团队在真实生产压力下替你试过了。
